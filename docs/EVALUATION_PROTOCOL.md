# 可复现评测协议

当前公开结果属于小样本历史诊断。尚未完成下述端到端对照实验，不能引用协议本身作为效果证据。

## 固定输入与环境

1. 版本化语料与问题集，记录文件 SHA-256、仓库 commit、切块配置及稳定的文档/块 ID。
2. 将可回答、信息不足、不可回答问题分组。为可回答问题人工标注相关文档 ID；调参集与最终测试集分离。
3. 记录 LLM/embedding/judge 的具体模型、提示词、依赖版本、温度、硬件、索引状态、缓存、重试及 token/费用。避免把不同长度的 chunk ID 当成相同相关性单位；跨切块策略建议统一到源文档 ID。
4. 所有方案使用同一问题集，保留每题原始检索结果、答案、引用和失败信息。不要只统计成功返回的样例。

## 对照方案

固定生成模型和上下文预算，比较 vector、vector + BM25、vector + BM25 + graph。分层切块及自反思另做独立开关实验，每次只改变一个因素。当前 `ablation_studies.py` 的 hybrid 分支未实现，不能列入已完成实验。

## 统一检索指标

每次运行导出 JSONL（下面仅为格式示例，不是实测结果）：

```json
{"query_id":"q1","relevant_ids":["doc-a"],"retrieved_ids":["doc-b","doc-a"],"latency_ms":120.0}
```

```bash
python evaluation/score_retrieval.py outputs/vector.jsonl --k 10 --output outputs/vector.metrics.json
```

评分器输出逐题与平均 Recall@k、MRR@k、二元相关性 nDCG@k 和延迟。比较前必须核对 query_id 与 relevant_ids 完全一致；内部相似度/图奖励分数不跨方案比较。无检索结果记为零，不能剔除；服务异常另行记录失败率。无相关文档的拒答问题单独统计，不混入这组检索指标。

## 生成与性能

- 生成：报告正确率、引用支持率、人工复核的忠实性，以及可回答问题的误拒答率和不可回答问题的正确拒答率。RAGAS 是模型判分信号，不是客观真值。
- 性能：固定并发、输入输出长度；先预热，再随机化方案执行顺序，多次重复。报告样本数、延迟 p50/p95、失败率与 token 成本，不把一次网络测量推广为整体加速。
- 报告：提供运行命令、配置、原始结果、逐题失败样例及不确定性；未执行或不支持的方案明确标记，不填入预期数值。
